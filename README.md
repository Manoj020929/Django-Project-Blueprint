Project Title: Google Applications – Integrated Web Platform

Technologies Used: Python, Django, HTML, CSS, JavaScript

Developed an integrated web application inspired by Google services using Python and Django for backend development and HTML, CSS, and JavaScript for frontend design.
The project consists of three independent applications: YouTube, Google Photos, and Google Maps.
YouTube provides a video browsing interface, Google Photos offers a photo gallery and album management interface,
and Google Maps provides an interactive map view with location exploration.
Implemented a modular Django application structure to organize the three apps and provide a user-friendly interface.

Modules Developed:
1. YouTube: Video browsing interface with search functionality and video display.
2. Google Photos: Photo gallery, albums, and image organization.
3. Google Maps: Map display, location exploration, and navigation interface.
Backend: Python, Django
Frontend: HTML, CSS, JavaScript
