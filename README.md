# Google Applications – Integrated Web Platform
**Technologies Used:** Python, Django 6, HTML5, CSS3, JavaScript
### Project Description
Developed a web application inspired by Google services using Python and Django for backend development and HTML, CSS, and JavaScript for frontend development. The project combines three popular Google applications—YouTube, Google Photos, and Google Maps—into a single platform with a simple and user-friendly interface.
### Modules
1. **YouTube:** Provides a video browsing page with search functionality and video display.
2. **Google Photos:** Provides a photo gallery to view and organize images into albums.
3. **Google Maps:** Displays an interactive map to explore different locations and places.
### Key Features
- Three applications integrated into one Django project.
- Simple and user-friendly interface.
- Separate Django apps for better project organization.
- Responsive frontend design.
### Technologies
- **Backend:** Python, Django 6
- **Frontend:** HTML5, CSS3, JavaScript
- **Architecture:** Django MVT (Model-View-Template)
